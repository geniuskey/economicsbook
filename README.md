# EconomicsBook — 경제 뉴스 읽는 교과서

기준금리를 올리면 대출·주식·집값·환율은 어떻게 움직이는가. 성장률 0.6%는 무엇과 비교한 숫자인가. 수요와 공급, GDP와 경기 순환, 고용, 물가와 금리, 중앙은행과 통화정책, 환율과 무역, 재정과 국가부채, 금융위기까지를 변수를 직접 바꾸며 배우는 한국어 인터랙티브 교과서입니다.
경제 기사를 읽다 막히는 사회초년생, 대출·투자를 시작한 직장인, 시사 상식이 필요한 수험생을 독자로 삼습니다. 본문은 일반인 기준으로 쓰고, 헤드라인이 만들어지는 사정과 흔한 오독은 "기자 노트", 원자료를 찾고 확인하는 법은 "통계 확인", 시리즈의 다른 책으로 이어지는 길은 "함께 읽기" 상자로 덧붙입니다.
책 전체가 가상의 인물 서지우(31, 식품 제조사 원료구매팀)가 2025년 10월부터 1년 동안 매달 경제 뉴스 헤드라인 하나를 골라 해석하는 노트(지우의 헤드라인 노트)를 따라가며, 외삼촌 백정호(전 경제신문 기자)가 질문을 던집니다.

배포 주소: https://economicsbook.euiyun.com/

## 실행
빌드 과정이 없는 정적 사이트입니다.

```bash
python3 -m http.server 8000   # → http://localhost:8000
```
`index.html`을 브라우저로 바로 열어도 동작합니다. KaTeX와 폰트는 CDN에서 불러오므로 인터넷 연결이 필요합니다.

공통 코드
- `css/style.css` — 디자인 토큰(라이트/다크), 기자 노트·통계 확인·함께 읽기 상자, 헤드라인 띠
- `js/common.js` — 내비게이션, 검색, 캔버스·차트·막대·도넛·끌기 헬퍼, 전역 `EB`
- `js/econ.js` — 공식 통계(`EC.KR`, `EC.HIST`, 출처·기준 시점 주석), 수요·공급, 성장률 변환, 채권·테일러 준칙, 기준금리 연결판 모형(`EC.transmit`), 작은 경제 모형(`EC.economy`), 부채 동학, 케이스(`EC.CASE`), 전역 `EC`
- `tools/head.py` — 챕터 `<head>`·사이트맵·JSON-LD 생성기
- `tools/check.py` — 페이지 점검기(콘솔 오류, 가로 넘침, 조작 중 예외)
- `SOURCES.md` — 통계 수치와 출처, 확인 상태, 헤드라인 노트 달력

레이아웃과 시뮬레이터 헬퍼는 같은 시리즈의 [EstateBook](https://github.com/geniuskey/estatebook)·[MoneyBook](https://github.com/geniuskey/moneybook)에서 가져왔습니다. 챕터 작성 규칙은 [CONTRIBUTING.md](CONTRIBUTING.md)를 참고하세요.

## 통계와 출처
통계는 한국은행, 국가데이터처(옛 통계청), 재정경제부(옛 기획재정부)·기획예산처, 산업통상부, 미국 연준 등의 공식 발표값이며 장마다 출처와 기준 시점을 숫자 곁에 밝혔습니다(작성 시점 2026년 10월 9일). 작성 환경에서 정부 사이트에 직접 접속하지 못해 공식 발표를 인용한 보도를 서로 대조해 확인했고, 확인 상태를 [SOURCES.md](SOURCES.md)에 적었습니다. 통계는 수정·갱신되므로 최신 값은 ECOS·KOSIS 원자료에서 확인하세요.

시뮬레이터는 원리를 보여 주는 교육용 모형입니다. 반응의 크기와 시차는 교육용 가정이며 경기·금리·환율·주가·집값을 전망하지 않습니다. 투자 자문이 아닙니다.
